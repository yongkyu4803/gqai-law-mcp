GQAI 법령조회 MCP

법제처 국가법령정보 OPEN API 기반 원격 MCP 서버. 별도 인증키 발급 없이 AI 클라이언트에서 법령·판례를 바로 조회합니다.

MCP 연결 주소
https://law.gqai.kr/mcp

임시 주소입니다. 정식 주소 law.gqai.kr 연결 후에는 커넥터 설정을 바꿔주세요.

연결 방법

Claude — 커넥터 추가

설정 → 커넥터 → 사용자 지정 커넥터 추가에서 위 주소를 입력합니다.

Cursor / Codex 등 — 설정 파일

{
  "mcpServers": {
    "gqai-law": {
      "url": "https://law.gqai.kr/mcp"
    }
  }
}

인증키 없이 사용할 수 있습니다. 직접 발급받은 법제처 인증키가 있다면 apiKey 헤더로 전달해 공용 한도와 무관하게 사용할 수 있습니다 (무료 발급: open.law.go.kr).

질문 예시

  • 근로기준법에서 연차휴가를 규정한 조문을 보여줘
  • 2020년 시점의 주택임대차보호법 제6조는 어떤 내용이었어?
  • 광진구 주차장 설치 조례에서 부설주차장 기준을 찾아줘
  • 전세사기 관련 최근 대법원 판례를 찾아줘
조회 결과는 참고용입니다 이 서비스는 법률 자문이 아니며, 조회·요약 과정에서 원문과 차이가 생길 수 있습니다. 법적 효력이 필요한 판단에는 반드시 국가법령정보센터 원문을 확인하세요.

이용 조건

  • 공용 인증키를 여러 사용자가 함께 쓰므로 분당·일일 조회 한도가 적용됩니다. 한도를 넘으면 잠시 후 재시도하라는 안내(HTTP 429)가 반환됩니다.
  • 대량·자동 수집 용도의 호출은 제한될 수 있습니다. 지속적인 대량 조회가 필요하면 법제처에서 직접 인증키를 발급받아 사용하세요.
  • 서비스는 예고 없이 점검·변경될 수 있습니다.

서비스 운영 방식

이 서버는 공용 인증키 하나를 여러 사용자가 나눠 쓰는 구조입니다. 그래서 조회 속도와 인증키 수명을 지키기 위한 장치를 두고 있습니다.

모든 조회에 공유 캐시가 걸립니다

법령·판례·조례·행정규칙·해석례 등 조회 종류를 가리지 않고 법제처로 나가는 모든 요청에 캐시가 적용됩니다. 누군가 이미 조회한 내용은 법제처를 다시 부르지 않고 즉시 응답합니다.

조회최초캐시 적중
법령 검색3,159ms154ms
판례 검색3,033ms268ms
조례 검색2,217ms307ms

캐시는 모든 사용자가 함께 사용하며, 서버 재배포·재시작 후에도 유지됩니다. 이용자가 늘고 조회가 쌓일수록 적중률이 올라갑니다.

인증키 사용량을 전역으로 관리합니다

공용 인증키의 분당·일일 사용량에 상한을 두고, 서버 인스턴스가 여러 개로 늘어나도 하나의 카운터로 합산합니다. 한 사용자의 과도한 호출이 다른 사용자의 조회를 막지 않도록 하기 위한 것입니다.

법제처 도달 상태를 매시간 점검합니다

캐시를 우회한 실제 조회로 법제처 응답을 매시간 확인하고 실패율을 기록합니다. 현재 캐시 적중률, 남은 일일 사용량, 점검 결과는 /health에서 누구나 확인할 수 있습니다.

데이터 출처

이 서비스가 반환하는 법령·판례·행정규칙·자치법규 본문은 전부 법제처 국가법령정보센터 OPEN API에서 조회한 것입니다. 데이터의 정확성·최신성은 원 제공처의 갱신 상태를 따릅니다.

개인정보 처리

  • 수집 항목: 접속 IP, 요청 시각, 요청 경로, User-Agent (서비스 운영·남용 방지 목적)
  • 조회 질의 내용은 응답 생성에만 사용하며 별도로 저장하지 않습니다.
  • 보관 기간: 배포 플랫폼(Vercel)의 로그 보존 정책에 따릅니다.

오픈소스 고지

이 서비스가 제공하는 법령·판례 조회 기능과 분석 도구는 전부 광진구청 류승인 주무관이 공개한 Korean Law MCP (MIT License)의 것입니다. GQAI는 이를 포크해 배포·운영 계층만 더했습니다.

원 저작자도 공개 서버를 직접 운영하고 있으며, 설치형으로 쓰거나 직접 호스팅할 수도 있습니다. 이 서비스의 소스는 GitHub에 공개되어 있습니다.

문의 및 오류 제보

조회 결과가 이상하거나 서비스가 응답하지 않으면 GitHub 이슈로 알려주세요. 어떤 질문을 했는지와 받은 응답을 함께 적어주시면 원인을 빨리 찾을 수 있습니다.
